## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Modern CSS with variables, grid, flexbox
- **JavaScript** — Vanilla JS with ES6+
- **Netlify** — Hosting and deployment

### Manual

```powershell
./deploy.ps1

./deploy.sh
```
